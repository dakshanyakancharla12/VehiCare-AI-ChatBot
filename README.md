# 🚗 Vehicare – AI Vehicle Service Chatbot

Vehicare is an AI-powered vehicle service appointment booking chatbot
designed to help users find service centers, check service information,
and manage vehicle service appointments.

## Features

- 🤖 AI-powered conversational chatbot
- 📅 Vehicle service appointment booking
- 🔄 Appointment rescheduling
- ❌ Appointment cancellation
- 📍 Service center information
- 🌐 Multilingual support
- 🛠️ Vehicle problem assistance
- 💬 Natural language interaction

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- NLP
- Machine Learning
- Google Translate
- JSON
